# 日本語の文章

日本語の執筆・編集・レビューには、同梱した `natural-japanese` を使う。
同梱した指示より、このスキルの制約と出力規則を優先する。

## 実行

1. まず [natural-japanese の指示](vendor/natural-japanese/INSTRUCTIONS.md)を読み、依頼に合うモードの手順に従う。
2. 指示内の `references/`、`scripts/`、`assets/` は、読み込んだ `INSTRUCTIONS.md` のディレクトリを基準に解決する。`skills/natural-japanese/` から始まるパスも同じ同梱先へ読み替える。内部文書の `SKILL.md` は、この `INSTRUCTIONS.md` を指す。
3. 検査には同梱したスクリプトの絶対パスを使い、対象ファイルも絶対パスで渡す。チャットの文章は一時ファイルで検査し、作業中に作った一時ファイルだけを終了時に削除する。
4. `uv` が使えない場合は、同梱した `references/manual-checklist.md` に従う。機械検査を実行したとは報告しない。

通常はクイックモードを使う。フルモードや診断の選択は、同梱した指示に従う。
このスキルへの `write` / `score` とモードの指定は、`natural-japanese` の同じ指定として解釈する。

## 優先する制約

同梱した指示を適用するときも、次の制約を守る。

- 事実、数量、条件、例外、不確実さ、時点や順序、義務と推奨の違いを保つ。一部の観察を全体の話に広げない。
- 原因、出典、意見、感情、体験を作らない。具体例が足りなければ、与えられた事実の範囲で書くか、必要な情報を求める。
- URL とコード、コマンド、識別子、パス、引用、製品名は、変更が依頼に含まれない限り、そのまま残す。
- 読み手、文体、形式、長さは依頼に合わせる。同じ意味には同じ語を使う。
- 本文の全角文字と半角英数字の間に半角スペースを入れる。

## 出力

提出前に原文と照合し、意味と技術的な表記が変わっていれば直す。
推敲では、依頼やこのルールに合わない箇所だけを直す。
説明を求められなければ、完成した文章だけを返す。
レビューでは、問題箇所、理由、修正案を返す。依頼がなければ全文を書き直さない。
診断では同梱した診断の形式で結果を返し、文章を書き換えない。
診断で lint を実行できない場合は、数値のスコアを出さず、未実施の検査と手動確認の所見を返す。
